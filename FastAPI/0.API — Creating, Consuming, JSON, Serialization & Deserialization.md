# API — Creating, Consuming, JSON, Serialization & Deserialization

## 1. Creating vs Consuming an API

There are two sides of an API:

```text
                 API
                  │
        ┌─────────┴─────────┐
        ↓                   ↓
    PROVIDER             CONSUMER
    (Server)             (Client)
        │                   │
    Creates API          Calls API
        │                   │
    FastAPI              requests
```

### Creating an API

You build the server/API that other applications can call.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users")
def get_users():
    return {
        "name": "Neeraj",
        "age": 25
    }
```

The client calls:

```text
GET /users
```

The API returns:

```json
{
    "name": "Neeraj",
    "age": 25
}
```

### Consuming an API

You call an API created by someone else.

```python
import requests

url = "https://api.example.com/users"

response = requests.get(url)

print(response.status_code)
print(response.text)

data = response.json()

print(data)
```

# 2. API Request

When consuming an API, a request can contain:

```text
HTTP Request
│
├── URL
├── HTTP Method
├── Headers
├── Authentication
├── Query Parameters
└── Body / Payload
```

Example:

```python
response = requests.post(
    url,
    headers=headers,
    json=payload
)
```

---

# 3. URL / Endpoint

The URL tells the client **where the request should go**.

```python
url = "https://api.example.com/users"
```

Here:

```text
https://api.example.com
        ↓
     API server

/users
   ↓
endpoint
```

---

# 4. HTTP Methods

The HTTP method tells the API **what operation you want to perform**.

```text
GET
→ Retrieve data

POST
→ Create/send data

PUT
→ Replace/update existing data

PATCH
→ Partially update existing data

DELETE
→ Delete data
```

Examples:

```python
requests.get(url)

requests.post(url)

requests.put(url)

requests.patch(url)

requests.delete(url)
```

---

# 5. Headers

Headers contain additional information/metadata about the request.

Example:

```python
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer abc123",
    "Accept": "application/json"
}
```

Common headers:

```text
Content-Type
Authorization
Accept
User-Agent
```

### `Content-Type`

Tells the server what format the request body is in.

```python
headers = {
    "Content-Type": "application/json"
}
```

Meaning:

```text
"I'm sending JSON data."
```

---

# 6. Authentication

Authentication is used to verify the identity/authorization of the caller.

A common approach is a Bearer token:

```python
headers = {
    "Authorization": "Bearer abc123"
}
```

The request becomes conceptually:

```text
Authorization: Bearer abc123
```

The server validates the token.

```text
Client
   ↓
Authorization header
   ↓
API
   ↓
Validate token
   ↓
Allow / Reject request
```

Another common method is Basic Authentication:

```python
response = requests.get(
    url,
    auth=("username", "password")
)
```

The authentication mechanism depends on the API.

---

# 7. Payload / Request Body

The payload is the actual data you send to the API.

Example:

```python
payload = {
    "name": "Neeraj",
    "age": 25
}
```

For a POST request:

```python
response = requests.post(
    url,
    headers=headers,
    json=payload
)
```

Conceptually:

```text
URL
 ↓
Headers
 ↓
Authentication
 ↓
Payload
 ↓
API
```

# 8. JSON

JSON stands for **JavaScript Object Notation**.

It is a common format for exchanging data between applications.

Example JSON:

```json
{
    "name": "Neeraj",
    "age": 25
}
```

JSON commonly represents:

```text
Object → {}
Array  → []
String → "hello"
Number → 25
Boolean → true / false
Null → null
```

---

# 9. Serialization

### Definition

**Serialization = converting a Python object into a format that can be transmitted or stored.**

For JSON:

```text
Python object
      ↓
Serialization
      ↓
JSON
```

Example:

```python
import json

data = {
    "name": "Neeraj",
    "age": 25
}

json_data = json.dumps(data)

print(json_data)
print(type(json_data))
```

Output:

```text
{"name": "Neeraj", "age": 25}
<class 'str'>
```

Notice:

```text
Python dict
     ↓
json.dumps()
     ↓
JSON string
```

`json.dumps()` performs **serialization**.

---

# 10. Deserialization

### Definition

**Deserialization = converting serialized data back into a Python object.**

For JSON:

```text
JSON
 ↓
Deserialization
 ↓
Python object
```

Example:

```python
import json

json_data = '{"name": "Neeraj", "age": 25}'

data = json.loads(json_data)

print(data)
print(type(data))
```

Output:

```text
{'name': 'Neeraj', 'age': 25}
<class 'dict'>
```

So:

```text
JSON string
     ↓
json.loads()
     ↓
Python dictionary
```

---

# 11. `json.dumps()` vs `json.loads()`

| Function       | Direction            | Operation       |
| -------------- | -------------------- | --------------- |
| `json.dumps()` | Python → JSON string | Serialization   |
| `json.loads()` | JSON string → Python | Deserialization |

### `json.dumps()`

```python
data = {
    "name": "Neeraj"
}

json_data = json.dumps(data)
```

```text
dict → JSON string
```

### `json.loads()`

```python
json_data = '{"name": "Neeraj"}'

data = json.loads(json_data)
```

```text
JSON string → dict
```

---

# 12. `requests.post(json=payload)`

Consider:

```python
import requests

payload = {
    "name": "Neeraj",
    "age": 25
}

response = requests.post(
    url,
    json=payload
)
```

Here, you **do not manually call `json.dumps()`**.

The `requests` library handles converting the Python data into JSON for the request.

Conceptually:

```text
Python dictionary
       ↓
   requests
       ↓
JSON serialization
       ↓
JSON request body
       ↓
API
```

So this:

```python
requests.post(
    url,
    json=payload
)
```

is convenient because `requests` handles the JSON serialization.

---

# 13. Using `data=` Instead

You can manually serialize the data and send it using `data=`.

```python
import json
import requests

payload = {
    "name": "Neeraj",
    "age": 25
}

payload_json = json.dumps(payload)

headers = {
    "Content-Type": "application/json"
}

response = requests.post(
    url,
    headers=headers,
    data=payload_json
)
```

Here:

```text
Python dictionary
       ↓
json.dumps()
       ↓
JSON string
       ↓
data=
       ↓
HTTP request
       ↓
API
```

You performed the serialization yourself.

---

# 14. `json=` vs `data=`

### Using `json=`

```python
payload = {
    "name": "Neeraj",
    "age": 25
}

response = requests.post(
    url,
    json=payload
)
```

`requests` handles JSON serialization.

### Using `data=`

```python
payload = {
    "name": "Neeraj",
    "age": 25
}

payload_json = json.dumps(payload)

response = requests.post(
    url,
    headers={
        "Content-Type": "application/json"
    },
    data=payload_json
)
```

You manually serialize the data.

### Easy comparison

```text
json=payload
    ↓
requests handles JSON serialization

data=json.dumps(payload)
    ↓
you handle JSON serialization
```

# 15. API Response

After processing the request, the API sends an HTTP response.

A response generally contains:

```text
HTTP Response
│
├── Status Code
├── Headers
└── Body
```

Example:

```text
HTTP/1.1 200 OK

Content-Type: application/json

{
    "id": 101,
    "name": "Neeraj"
}
```

# 16. Status Code

The status code tells you what happened.

Common codes:

```text
200 → Success
201 → Created
400 → Bad Request
401 → Unauthorized
403 → Forbidden
404 → Not Found
500 → Server Error
```

In Python:

```python
print(response.status_code)
```

Output:

```text
200
```

# 17. `response.text`

`response.text` gives you the response body as text.

```python
response = requests.get(url)

print(response.text)
```

If the API returns:

```json
{
    "name": "Neeraj",
    "age": 25
}
```

then:

```python
response.text
```

is essentially the JSON content represented as a Python string.

Conceptually:

```text
HTTP Response Body
        ↓
response.text
        ↓
Python string
```

---

# 18. `response.json()`

If the API response contains JSON, you can use:

```python
data = response.json()
```

Example API response:

```json
{
    "name": "Neeraj",
    "age": 25
}
```

Python:

```python
response = requests.get(url)

data = response.json()

print(data)
print(type(data))
```

Output:

```text
{'name': 'Neeraj', 'age': 25}
<class 'dict'>
```

Now you can access the data:

```python
print(data["name"])
```

Output:

```text
Neeraj
```

Conceptually:

```text
JSON response
      ↓
response.json()
      ↓
Python dictionary/list
```

---

# 19. `response.json()` vs `json.loads()`

These are related but not exactly the same.

### `json.loads()`

You already have a JSON string:

```python
import json

json_string = '{"name": "Neeraj", "age": 25}'

data = json.loads(json_string)
```

Flow:

```text
JSON string
    ↓
json.loads()
    ↓
Python dict
```

### `response.json()`

You have an HTTP response object:

```python
response = requests.get(url)

data = response.json()
```

Flow:

```text
HTTP response
     ↓
response.json()
     ↓
JSON body parsed
     ↓
Python dict
```

So:

```text
json.loads()
→ Works with a JSON string

response.json()
→ Works with an HTTP response
```

---

# 20. `json.dumps()` vs `response.json()`

This is one of the most important distinctions.

### `json.dumps()`

Used when **sending/converting Python data to JSON**:

```python
data = {
    "name": "Neeraj"
}

json_data = json.dumps(data)
```

```text
Python → JSON
```

### `response.json()`

Used when **receiving JSON from an API**:

```python
response = requests.get(url)

data = response.json()
```

```text
JSON → Python
```

Remember:

```text
json.dumps()
    Python → JSON

response.json()
    API JSON response → Python
```

# 21. Complete API Consumption Example

```python
import requests

url = "https://api.example.com/users"

headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer abc123"
}

payload = {
    "name": "Neeraj",
    "age": 25
}

response = requests.post(
    url,
    headers=headers,
    json=payload
)

print("Status:", response.status_code)
print("Response:", response.text)

data = response.json()

print("Data:", data)
```

Flow:

```text
                 CLIENT
                    │
                    │
              Python dict
                    │
                    ↓
              requests.post()
                    │
          ┌─────────┴─────────┐
          │                   │
       Headers             Payload
          │                   │
    Authorization          JSON data
    Content-Type               │
          │                   │
          └─────────┬─────────┘
                    ↓
                  API
                    │
             Validate Auth
                    ↓
             Process Request
                    ↓
                Response
                    │
          ┌─────────┴─────────┐
          │                   │
     Status Code          JSON Body
          │                   │
         200                   │
                              ↓
                       response.json()
                              ↓
                        Python dict
```

# 22. Complete End-to-End Serialization Flow

When **sending data**:

```text
Python Dictionary
       ↓
Serialization
       ↓
JSON
       ↓
HTTP Request
       ↓
API Server
```

When **receiving data**:

```text
API Server
       ↓
JSON Response
       ↓
Deserialization
       ↓
Python Dictionary
```

Complete picture:

```text
                  CLIENT
                    │
              Python object
                    │
                    ↓
              SERIALIZATION
                    │
              Python → JSON
                    │
                    ↓
               HTTP REQUEST
                    │
                    ↓
                  SERVER
                    │
             DESERIALIZATION
                    │
                JSON → Python
                    │
                    ↓
              Process request
                    │
                    ↓
              Python response
                    │
                    ↓
              SERIALIZATION
                    │
              Python → JSON
                    │
                    ↓
              HTTP RESPONSE
                    │
                    ↓
                  CLIENT
                    │
             response.json()
                    │
             DESERIALIZATION
                    │
                JSON → Python
                    │
                    ↓
              Python object
```

# 23. Quick Cheat Sheet

```text
API PROVIDER
→ Creates/builds the API
→ Example: FastAPI

API CONSUMER
→ Calls an API
→ Example: requests

URL
→ Where to send the request

HTTP Method
→ GET / POST / PUT / PATCH / DELETE

Headers
→ Metadata/information about the request

Authorization
→ Authentication/permission information

Payload
→ Data sent to the API

Response
→ Data returned by the API

Status Code
→ Tells whether the request succeeded/failed

response.text
→ Response body as a string

response.json()
→ API JSON response → Python object

json.dumps()
→ Python object → JSON string
→ Serialization

json.loads()
→ JSON string → Python object
→ Deserialization

requests(..., json=payload)

```

```text
                    SENDING
                       ↓
              Python Dictionary
                       ↓
                 SERIALIZATION
                       ↓
                     JSON
                       ↓
                     API


                    RECEIVING
                       ↓
                  JSON Response
                       ↓
                DESERIALIZATION
                       ↓
                 Python Dictionary
```
